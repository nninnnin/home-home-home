# home-home-home

당신은 SNS에 몇 개의 계정을 갖고 있나요?

피드를 스크롤하고, 알림을 확인하고, 누군가의 타임라인 위에 잠시 머물다 사라지는 것.
우리는 점점 더 많은 시간을 온라인에서 보내지만, 정작 **내 것**이라고 느껴지는 공간은 없습니다.

**home-home-home**은 소셜 피드 대신 집을 만듭니다.

3D로 구현된 방 안에 책상이 있고, 그 위에 노트가 놓여있습니다.
액자에는 사진이 걸려있고, 구석의 LP 플레이어에서는 음악이 흘러나옵니다.
다락방에는 오래된 기록들이 쌓여있고, 창문 너머로 이웃집 불빛이 보입니다.

이 모든 것은 **당신의 URL**에 있습니다.
